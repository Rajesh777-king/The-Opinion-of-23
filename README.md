# The Opinion of 23

A personal opinion blog by Rajesh M Patil, designed as an editorial magazine with a cream background, navy typography, serif headlines and restrained warm accents. English-only starter. Built with HTML, CSS and JavaScript.

## Files
- `index.html` — homepage and article cards
- `article.html` — reusable article page
- `about.html` — author and writing principles
- `styles.css` — responsive editorial design
- `script.js` — article content, category filtering and rendering
- `assets/` — article cover images

## Preview locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use VS Code Live Server.

## Edit or add articles
Edit the `articles` array in `script.js`. Each entry includes a unique `slug`, title, category, date, image path, excerpt, paragraphs and a source note. Put cover images in `assets/` and use a relative path such as `assets/my-cover.png`. The included article text is starter copy: verify facts and add links to original reporting before public release.

## Publish on GitHub Pages for free
1. Sign in at https://github.com/ or create an account.
2. Create a **public repository** named `the-opinion-of-23`.
3. Upload the *contents* of this folder to the repository root (not the enclosing folder). Confirm `index.html` is directly at the root.
4. Open **Settings → Pages**.
5. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
6. After deployment, the site address will be `https://YOUR-USERNAME.github.io/the-opinion-of-23/`. Replace `YOUR-USERNAME` with your GitHub username.
7. Future commits to `main` will trigger redeployment.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Enable reader comments with Giscus
Comments are not active until configured. Giscus uses GitHub Discussions; readers must sign in with GitHub to comment.
1. In the repository, enable **Discussions** under Settings → General → Features.
2. Visit https://giscus.app and enter your repository name (`YOUR-USERNAME/the-opinion-of-23`).
3. Follow its setup flow, choose a Discussion category and `pathname` mapping, and authorize the app for your repository.
4. Add the configuration generated by Giscus to the `.giscus` container in the article template in `script.js`, replacing the placeholder. Use only the configuration generated for your repository.
5. Commit the changes and test comments on the live website.

## Before launch
- Review article drafts.
- Add links to original reporting and verify claims, dates, figures and quotations.
- Decide whether to keep your full author name public.
- Test on desktop and mobile.
- Add a comment moderation policy.
